Sorting ruleskeyword lists for each category

Each entry's text is checked against these keywords. When an entry matches several categories, the one listed first wins. Plurals and -ing forms match automatically (pitch matches pitches and pitching). Keywords in capitals, such as BD or CPD, match only in capitals.
